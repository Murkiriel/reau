Which APK to download

On the Releases page, download the file of the edition you chose. The file name tells you which one it is:

  • REau-0.1.0-lite.apk: the Lite edition, the recommended one, which does not use the Accessibility service.
  • REau-0.1.0-completa.apk: the Full edition (“Completa” is Portuguese for Full), which uses Accessibility and has the warning about banking apps.

0.1.0 is the version and changes with each Release. When in doubt, download the file with “Lite” in its name. Ignore the “Source code” items (zip and tar.gz): they are the source code and cannot be installed.

⚠️ Warning: the Full edition and banking apps. The Full edition uses Android’s Accessibility service. Some apps, mainly banking apps, treat third-party Accessibility as a risk and may refuse to open or to sign in, and there are reports of the block continuing even after uninstalling REau. If you use a banking app, use the Lite edition, which does not use Accessibility. If you already installed Full and an app refused to open, turn REau’s Accessibility off in Android’s settings and switch to Lite.

The path in short

  1. Pick the edition (Lite recommended) and install the APK from the Releases page; updates install over the old one.
  2. Open REau, accept the terms and allow location (only to find the dash’s Wi-Fi) and the suggested Wi-Fi networks.
  3. Turn on Android Auto developer mode (about 10 taps on Version) and start the head unit server (by hand on Lite; by itself on Full, with Accessibility).
  4. Turn the bike on, tap Turn on and, the first time, Connect. With Android Auto Active and the dash Ready, it is streaming.
